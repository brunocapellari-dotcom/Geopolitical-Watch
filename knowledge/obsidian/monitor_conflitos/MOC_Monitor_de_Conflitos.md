# MOC — Monitor de Conflitos / Geopolitical Watch

## Função
Este MOC é a entrada canônica do Segundo Cérebro para o Geopolitical Watch. O GitHub é a verdade do código; este vault é a memória técnica, metodológica e histórica interpretada do projeto.

## Regras permanentes
- Todo conhecimento técnico, decisão, experimento, fonte, falha e conclusão relevante deve gerar nota ou evidência vinculada.
- Resultados negativos são preservados.
- Fato observado, cálculo, inferência, estimativa, projeção e sinal são categorias distintas.
- Perfil de país, grafo, analogia histórica e criticidade estrutural são contexto; não confirmam eventos ao vivo.
- `EvidenceStrength` não é probabilidade.
- Forecast probability não altera EvidenceStrength.
- Context-only (GDACS/FIRMS etc.) não cria episódio de conflito sozinho.
- Human-gold exige decisão humana explícita; research-coded ou heurístico não é gold.
- Missing data não é zero.
- Fonte indisponível e falha interna do sistema devem permanecer distinguíveis.
